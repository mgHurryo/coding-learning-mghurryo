## 二、数据流全链路

### 注册

```
POST /register → @Valid → Service.findByUserName() → Md5Util → Mapper.add() → Result.success()
```

### 登录

```
POST /login → @Valid → Service.findByUserName() → Md5Util.checkPassword() → JwtUtil.generateToken() → Result.success(token)
```

### 查询信息（需认证）

```
JwtFilter验证Token → Controller → Service.findByUserName() → Result.success(User)
```

### 修改密码（需认证）

```
JwtFilter验证Token → @Valid → Token提取用户名 → 旧密码验证 → 新密码加密 → Mapper.updatePwd()
```
