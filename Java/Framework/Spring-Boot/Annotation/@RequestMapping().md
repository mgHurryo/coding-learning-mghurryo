# `@RequestMapping()`

此注解的意义为:
- 统一请求路径
- 标明具体接口路径
- 指定请求方式 (e.g. `@GetMapping()`, `@PutMapping()`, `@PostMapping()`, `DeleteMapping()`)
	- 具体请求方式, 像是 GET, PUT, POST, DELETE, 可以在 [请求方法MOC](../../../../Network/HTTP/MOC.md) 中查看
