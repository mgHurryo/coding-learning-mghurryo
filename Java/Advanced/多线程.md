# 多线程

## 线程池多大

### CPU密集型

CPU支持的最大并行数+1

### I/O密集型

CPU的最大并行数 ✖️期望CPU利用率✖️（（CPU计算时间+等待时间）/ CPU计算时间）

## 与 Web 后端的关系

Spring Boot Web 请求最终由服务器线程处理。数据库访问、外部 HTTP 调用、文件 I/O 等等待时间较多的操作，会让接口表现出 I/O 密集型特征。

在 Big-event 这类后端项目中，可以建立以下关联：

- Controller / Service 的一次请求会占用服务端处理线程。
- MyBatis 查询数据库属于 I/O 操作。
- 密码哈希、JWT 签名校验属于 CPU 操作，但通常耗时较短。
- 线程池大小、数据库连接池大小和接口吞吐量会互相影响。
