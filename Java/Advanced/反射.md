# 反射

步骤：
1. 获取class对象
2. 从class中找到构造方法/字段/方法
3. 如果是 private， 则先设`setAccessible(true)`
4. 创建对象
5. 调用方法/读写字段
6. 处理异常

## 获取`Class`对象

### 方式

1. `Class.forName("类名")` 只有字符串, 在运行时才开始查找类
2. `类名.class`  写代码时知道类是谁
3. `对象.getClass()` 当手中已经有对象了, 想知道他的真实类型

### 用途

1. `Class.forName("类名")`
	- 代码写死时不知道需要用哪个类,只有运行时才知道
	- 其中类名必须写完整类名, 一般包含包名
2. `类名.class`
	- 反射时传参数类型
3. `对象.getClass()`
	- 不清楚变量实际指向的是哪个子类, 但是想知道他运行时真正是什么类型

## 与 Spring Boot 的关系

Spring Boot 的组件扫描、自动配置、注解解析、Bean 创建都大量依赖反射和元数据读取。

可以把反射理解为 Spring 框架“运行时认识类”的基础能力：

- `@SpringBootApplication` 触发组件扫描和自动配置。
- `@Configuration` 配置类会被解析，`@Bean` 方法会注册对象。
- `@Autowired` 按类型或名称找到依赖并注入。
- MyBatis 也会根据 Mapper 接口创建代理对象。
