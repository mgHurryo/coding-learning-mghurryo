## UDP

### 发送数据

1. 创建发送端的 Datagram Socket 对象
2. 数据打包（使用DatagramPacket）
3. 发送数据
4. 释放资源
```Java

// 1. Create DatagramSocket Object, just like a express delivery company
// Detail
// 1. If we take a variable to create this object, this means that we specified a port.
// 2. If we don’t use any variable to create this object, it will specified a vail and random port by itself.

public static void main(String[] tags) throws SocketException {
	// Create DatagramSocket Object (Random port for sender)
	DatagramSocket ds = new DatagramSocket();
	
	// Data
	String str = “Data”;
	byte[] bytes = str.getBytes();
	
	// IP Adress
	InetAddress adress = InetAddress.getByName(“127.0.0.1”);
	
	// Port (Specified port for receiver)
	int port = 10088;
	
	// Pack the Data
	DatagramPacket dp = new DatagramPacket(bytes, bytes.length, address, port);
	
	// Send
	ds.send(dp);
	
	// Release resources
	ds.close();
}
```

### Receive Data

1. Create DatagramSocket Object for receive end
2. Get Data with packeted
3. Analysis the data(Unpack)
4. Release the resource

```Java

// 1. In the front, we specified a port which is 10088, so if we want to get the message from it, we need to specified a port which is same as sender specified.
public static void main(String[] args) {
	// Create DatagramSocket
	DatagramSocket ds = new DatagramSocket(10088);
	
	// Data packet
	// Buffer
	byte[] bytes = new byte[1024];
	// Create Packet object and throws data in the buffer
	DatagramPacket dp = new DatagramPacket(bytes, bytes.length);
	
	// Start receive data
	ds.receive(dp);
	
	// Unpack Data packet
	// Get data
	byte[] data = dp.getData();
	
	// Get data length
	int len = dp.getlength();
	
	// Get sender IP
	InetAddress address = dp.getAddress();
	
	// Get sender port
	int port = dp.getPort();
	
	// Release resource
	ds.close();
}
```

> ***Important***
> 
> 在使用`ds.receive(dp);`方法的时候，我们需要注意他是堵塞的。 也就是说， 当使用使用他的时候，他会阻塞线程运行。
>
>如果一直没有接受到数据的话，线程会一直停在这一步，所以对于特定场景，设计一个超时机制是必要的。

### Unicast(单播), Multicast(组播), Broadcast(广播)

#### Unicast

- One-to-one (One sender, one receiver)

#### Multicast

- One-to-group (One sender, one group(multi receiver))

>IP Address for multicast: `224.0.0.0 ~ 239.255.255.255`
>
>`224.0.0.0 ~ 224.0.0.255` 是预留的组播地址
#### Broadcast

- One-to-broad (One sender, all computer in the LAN(局域网))

> IP Address for broadcast: `255.255.255.255`


## TCP

- In Java, we use Socket to make I/O Stream for realize TCP 

> **Important**
>
>For sender, the stream is `OutputStream`
>For receiver, the stream is  `InputStream`

### Sender

1. Create client Socket object(`Socket`) and connect with specified receiver (If connected fail in this stage, it will throws  `ConnectException`)
2. Get `OutputStream`, output data
3. Release resources

```Java

public static void main(String[] args) {
	
	// Create Socket object
	// 1. When we create this object, it will try to link the receiver, if fault, throws ConnectException
	// 127.0.0.1 hosts, 10088 port
	Socket socket = new Socket(“127.0.0.1“, 10088); 
	
	// Get the Output stream from connection port directly
	OutputStream os = socket.getOutputStream();
	
	// Write data
	os.write(“hello”.getBytes());
	
	// Release resources
	os.close();
	socket.close();
}
```

### 三握四挥

三次握手建立连接：

1. 一握：客户端向服务端发起请求（我要与你建立连接）对应TCP：`SYN`
2. 二握：服务端向客户端发送回应（我收到了你的请求，我也准备与你连接）对应TCP：`SYN`+`ACK`
3. 三握：客户端向服务端发起确认（收到确认，开始传输数据）对应TCP：`ACK`

四次挥手断开连接：

1. 一挥：客户端向服务端发送消息（客户端数据已经全部送达，准备断开）对应TCP：`FIN`
2. 二挥：服务端向客户端发送回应（收到客户端数据全部送达的消息）对应TCP：`ACK`
	- 请注意，此时服务端可能不回马上断开连接，因为此时服务端k可能还有数据需要发给客户端。
3. 三挥：服务端向客户端发送消息（服务端数据已经全部发送，准备断开）对应TCP：`FIN`
4. 四挥：客户端向服务端发送确认（收到服务端消息，断开连接）对应TCP：`ACK`
