# MySQL 数值函数

## 常用函数表

| 函数 | 示例 | 说明 |
| :--- | :--- | :--- |
| `ABS` | `ABS(-8)` | 绝对值 |
| `ROUND` | `ROUND(12.345, 2)` | 四舍五入到指定小数位 |
| `TRUNCATE` | `TRUNCATE(12.359, 2)` | 直接截断，不四舍五入 |
| `CEIL` / `CEILING` | `CEIL(2.1)` | 向上取整 |
| `FLOOR` | `FLOOR(2.9)` | 向下取整 |
| `MOD` | `MOD(10, 3)` | 求余数，结果为 1 |
| `POWER` | `POWER(2, 3)` | 指数运算 |
| `SQRT` | `SQRT(9)` | 平方根 |
| `RAND` | `RAND()` | 返回 0（含）到 1（不含）的随机数 |

## 金额示例

```sql
SELECT
    price,
    quantity,
    ROUND(price * quantity, 2) AS amount
FROM order_item;
```

金额字段应使用 `DECIMAL`，并在明确的业务边界进行舍入。不要把 `FLOAT` 或 `DOUBLE` 的二进制近似值当作精确金额。

## 取整方向

`FLOOR(-2.1)` 的结果是 -3，`CEIL(-2.1)` 的结果是 -2；它们不是简单地“去掉小数”。如果需求是向零截断，应使用 `TRUNCATE(number, 0)`。

## 常见错误与性能

- `ROUND` 的第二个参数为负数时，会舍入到十位、百位等更高位。
- 除数为 0 会产生错误或警告；业务 SQL 可用 `NULLIF(divisor, 0)` 防止异常。
- `ORDER BY RAND()` 需要为大量行生成随机值并排序，不适合大表。
- 计算列用于筛选时，先评估是否能改写为对常量计算，以保留索引可用性。
