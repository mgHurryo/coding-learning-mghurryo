# 回表

## 速览

回表是指通过二级索引找到主键后，再用主键去聚簇索引读取完整行。它是 InnoDB 二级索引查询中常见的额外成本。

## 核心机制

二级索引叶子节点不保存整行，只保存索引列和主键值。查询字段如果不在二级索引里，MySQL 需要按主键再次访问聚簇索引。少量回表没问题，大量回表会导致随机访问增多。

## SQL/配置示例

```sql
CREATE INDEX idx_user_status ON article(user_id, status);
SELECT title FROM article WHERE user_id = 1 AND status = 1;
```

如果 `title` 不在索引中，就可能需要回表。

## 项目落地

高频列表页可以把筛选字段、排序字段和少量展示字段组合成覆盖索引，减少回表。详情页按主键查整行，回表问题通常不明显。

## 常见错误

不要为了完全避免回表而创建过宽索引；索引宽度会增加写入成本、缓存占用和页分裂概率。
