# 选择性与基数

## 速览

基数是字段不同值的估算数量，选择性是不同值数量相对总行数的比例。它们用于判断索引能否有效缩小扫描范围。

## 核心机制

`SHOW INDEX` 中的 `Cardinality` 是优化器使用的重要统计信息之一，但它是估算值。高基数字段通常更适合做索引前导列；低基数字段更适合作为联合索引中的补充过滤条件。

## SQL/配置示例

```sql
SHOW INDEX FROM user;
ANALYZE TABLE user;
```

## 项目落地

当发现优化器没有选择预期索引时，可以检查统计信息是否过旧、数据是否倾斜、条件是否低选择性。

## 常见错误

不要把 `Cardinality` 当成绝对精确值；不要只看选择性，忽略排序、覆盖索引和业务查询稳定性。
