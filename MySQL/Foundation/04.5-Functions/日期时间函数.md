# MySQL 日期时间函数

## 常用函数表

| 函数 | 示例 | 作用 |
| :--- | :--- | :--- |
| `CURRENT_DATE()` | `CURRENT_DATE()` | 当前日期 |
| `NOW()` | `NOW()` | 当前日期和时间 |
| `DATE` | `DATE(create_time)` | 取日期部分 |
| `YEAR` / `MONTH` / `DAY` | `YEAR(create_time)` | 提取年月日 |
| `DATE_ADD` | `DATE_ADD(NOW(), INTERVAL 7 DAY)` | 增加时间间隔 |
| `DATE_SUB` | `DATE_SUB(NOW(), INTERVAL 1 MONTH)` | 减少时间间隔 |
| `DATEDIFF` | `DATEDIFF(end_date, start_date)` | 返回相差天数 |
| `TIMESTAMPDIFF` | `TIMESTAMPDIFF(HOUR, start, end)` | 按单位计算时间差 |
| `DATE_FORMAT` | `DATE_FORMAT(create_time, '%Y-%m')` | 格式化为字符串 |
| `STR_TO_DATE` | `STR_TO_DATE('2026-07-20', '%Y-%m-%d')` | 按格式解析字符串 |

## 日期范围查询
不要把索引列包在 `DATE` 中：

```sql

-- 容易让普通索引失去直接定位能力
WHERE DATE(create_time) = '2026-07-20'

-- 推荐的半开区间写法
WHERE create_time >= '2026-07-20'
  AND create_time <  '2026-07-21'
```

半开区间包含起始时刻、不包含结束时刻，适合 `DATETIME`，也不会漏掉当天最后一秒的小数部分。

## 时间间隔语法

```sql
SELECT DATE_ADD('2026-01-31', INTERVAL 1 MONTH);
SELECT TIMESTAMPDIFF(DAY, '2026-07-01', '2026-07-20');
```

月份加减遇到月末时，结果可能被调整到目标月份的最后一天。跨时区业务应明确应用层时区、会话时区和存储类型；不要只依赖服务器默认时区。

## 易错点

- `DATEDIFF` 只计算日期部分，忽略时分秒；需要精确单位时用 `TIMESTAMPDIFF`。
- `DATE_FORMAT` 返回字符串，不再是日期类型。
- `NOW()` 依赖执行时间；回放测试时要固定时间或传入参数。
- 解析失败可能返回 `NULL` 并产生警告，导入数据前应校验格式。
