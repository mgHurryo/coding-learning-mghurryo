# 多表查询

初级的多表查询使用

```SQL

SELECT * FROM stu, class
```

但是这样, 会出现笛卡尔积, 也就是说, stu中每个学生都会与每个class组合一遍. 那么我们假设, stu表中已有外键关联了class的id列, 则我们可以通过使用 `WHERE` 来筛除.

```SQL

SELECT * FROM stu, class WHERE stu.class_id = class.id;
```

这样, 可以避免无效的笛卡尔积, 查询到关联的数据.

## 多表查询分类

- 连接查询
	- 内连接: 相当于查询 A, B 表交集部分的数据
	- 外连接:
		- 左外连接: 查询左表所有数据以及两张表交集的数据
		- 右外连接: 查询右表所有数据以及两张表交集的数据
	- 自连接: 当前表与自身的连接查询, 自连接必须使用表别名
- 子查询

### 连接查询
#### 内连接

内连接还分为 **隐式内连接** 还有 **显式内连接**. 在实际业务中, 通常使用 **显式内连接** 来保持代码可读性, 以及可维护性.

##### 隐式内连接

```SQL

SELECT * FROM stu, class WHERE stu.class_id = class.id;
```

在前面的演示中, 我们使用的就是内连接中的隐式内连接. 

这里, `WHERE` 的连接匹配与正常业务中逻辑匹配混合到一起了, 因此不方便后续的维护和可读性. 因此现在都很少使用这种写法.

##### 显式内连接

```SQL

SELECT * FROM stu AS s
INNER JOIN class AS c
	ON s.class_id = c.id
WHERE [业务筛选条件];
```

> [!tips] Tips
> `INNER`可以被省略, 直接 `JOIN` 即可
> `AS` 可写可不写, 写了更清晰, 不写也行

> [!warning] Warning
> 需要注意的是, 在使用了别名以后, 后续该语句中所有条件都必须使用别名, 而不能是表名

这个与隐式内连接最大的区别是, 连接逻辑和业务逻辑被分开了, 一个是写在 `JOIN` 后面, 一个是写在`WHERE` 中. 所以现代如果需要内连接, 一般都会选择显式内连接.

#### 外连接

##### 左外连接

```SQL

SELECT * FROM stu AS s
LEFT OUTER JOIN class AS c
	ON s.class_id = c.id
WHERE [业务逻辑]
```

左外连接会查询 s 的所有被 `WHERE` 选中的数据, 如果 s 中有数据没有链接到 c 上, 那么那一栏会变为空值, 右外连接逻辑相同.

##### 右外连接

```SQL

SELECT * FROM stu AS s
RIGHT OUTER JOIN class AS c
	ON s.class_id = c.id
WHERE [业务逻辑]
```

> [!tips] Tips
> 左右表如何区分: `FROM`之后的就是左表, `JOIN`之后的就是右表

#### 自连接

语法与内连接相同, 但是请注意的是, 自连接既可以内连接, 又可以是外连接

```SQL

SELECT * FROM stu AS s
INNER JOIN stu AS s2
	ON s.manager_id = s2.id
```

### 联合查询

将多次查询的结果合并, 形成一个新的查询集

```SQL

SELECT * FROM stu1
UNION [ALL]
SELECT * FROM stu2
```

此时, 就会将 stu1 的结果与 stu2 的结果合并并返回.

> [!Warning] Warning
> 使用 `UNION` 查询出来的列数量需要相同, 且各列的数据类型必须兼容.

> [!tips] Tips
> 联合查询如果添加了 `ALL` 字段, 不会自动去重. 如果只有 `UNION` 字段, 那么会自动去重, 通常, 如果说数据无需去重, 那么还是添加 `ALL`.

### 子查询

在 SQL 语句中嵌套查询语句.

```SQL

SELECT * FROM stu1 AS s WHERE s.class_id = (
	SELECT c.id FROM class AS c WHERE c.name = "一班"
)
```

> [!warning] Warning
> `=` 只能返回一个值, 如果需要多个返回值, 则需要使用 `IN`

```SQL

SELECT * FROM stu1 AS s WHERE s.class_id = (
	SELECT c.id FROM class AS c WHERE c.name IN ("一班", "二班")
)
```

#### 子查询的多种使用方法

##### 标量子查询

子查询只返回一个值.

```SQL

SELECT * FROM stu WHERE stu.age > (
		SELECT AVG(stu.age) FROM stu
	)
```

##### 列子查询

子查询只返回一列.

```SQL

SELECT * FROM stu
WHERE class_id IN (
    SELECT id FROM class WHERE class_name IN ('一班', '二班')
);
```

##### 行子查询

子查询只返回一行.

```SQL

SELECT * FROM stu WHERE (class_id, age) = (
    SELECT class_id, age FROM stu WHERE id = 1
);
```

> [!warning] Warning
> 在使用行子查询时, 各个列的数量必须相同, 且数据类型兼容.

##### 表子查询

子查询只返回一个临时表. 这个表相当于是一个正常的表, 可以使用 SQL 语句在当前语句中正常访问.

```SQL

SELECT * FROM (
    SELECT
        class_id,
        AVG(age) AS avg_age,
        COUNT(*) AS student_count
    FROM stu GROUP BY class_id
) AS t;
```
