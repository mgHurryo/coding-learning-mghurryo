# 幂等写入

## 速览

幂等写入是指同一个业务请求重复执行多次，最终效果仍然等同于执行一次。数据库层常用唯一键和状态条件兜底。

## 核心机制

为业务请求设计稳定幂等键，例如 `request_id`、`order_no`、`message_id`。插入时依赖唯一约束避免重复；更新时带上当前状态条件，防止已完成记录被重复处理。

## SQL/配置示例

```sql
INSERT INTO request_log(request_id, status)
VALUES (?, 'SUCCESS')
ON DUPLICATE KEY UPDATE request_id = request_id;

UPDATE order_info SET status = 'PAID'
WHERE order_no = ? AND status = 'WAIT_PAY';
```

## 项目落地

支付回调、消息消费、创建订单、发券等场景必须有幂等设计。Service 层判断业务语义，数据库唯一键提供最终保护。

## 常见错误

不要每次重试生成新 request_id；不要只靠应用内存去重；不要没有唯一约束就相信接口不会重复调用。
