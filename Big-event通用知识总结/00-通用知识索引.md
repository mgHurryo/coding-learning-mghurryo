# Big-event 通用知识点总结

> 这里总结的是从 Big-event 项目中抽取出来的通用知识点，重点放在以后写其他 Spring Boot 后端项目也能复用的部分。

## 知识地图

| 模块 | 适合解决的问题 | 笔记 |
|------|----------------|------|
| Spring Boot 与 Web 基础 | 如何启动项目、接收请求、返回 JSON、校验参数 | [[01-SpringBoot与Web基础]] |
| 认证安全与异常处理 | 如何做登录态、JWT、接口保护、统一错误响应 | [[02-认证安全与异常处理]] |
| 数据持久化与配置 | 如何连接数据库、写 SQL、完成对象和表字段映射 | [[03-数据持久化与配置]] |
| 工程分层与代码简化 | 如何组织 Controller、Service、Mapper、DTO、POJO | [[04-工程分层与代码简化]] |

## 通用知识总表

| 分类 | 核心知识点 |
|------|------------|
| Spring Boot | `@SpringBootApplication`、自动配置、IoC 容器、依赖注入、配置类 |
| Spring MVC | `@RestController`、请求映射、参数绑定、JSON 响应 |
| API 设计 | RESTful 方法语义、统一响应对象、DTO 入参模型 |
| 数据校验 | `@Valid`、`@Validated`、`@Pattern`、`@NotBlank`、`@Email`、`@AssertTrue` |
| 安全认证 | Spring Security、过滤器链、无状态会话、接口白名单 |
| JWT | Token 结构、生成、解析、过期时间、签名校验 |
| 异常处理 | `@RestControllerAdvice`、`@ExceptionHandler`、全局兜底和精确异常 |
| 数据库 | DataSource、JDBC URL、MySQL 驱动、UTF-8 参数 |
| MyBatis | `@Mapper`、`@MapperScan`、注解式 SQL、`#{}` 预编译参数 |
| 架构设计 | Controller-Service-Mapper 三层架构、DTO/POJO 分离 |
| 代码简化 | Lombok、静态工厂方法、接口与实现分离 |
| 密码安全 | 摘要算法、MD5 风险、BCrypt 替代方案 |

## 推荐复习顺序

1. 先看 [[04-工程分层与代码简化]]，建立项目整体结构感。
2. 再看 [[01-SpringBoot与Web基础]]，理解请求如何进入系统。
3. 接着看 [[03-数据持久化与配置]]，理解数据如何落库。
4. 最后看 [[02-认证安全与异常处理]]，补齐登录、权限和错误处理。
