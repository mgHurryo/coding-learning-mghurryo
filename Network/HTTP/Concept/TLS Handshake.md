# TLS Handshake

## 定义

TLS 握手是客户端与服务器在建立 HTTPS 连接时，协商加密算法、验证身份并生成会话密钥的过程。

## TLS 1.2 握手流程

1. **Client Hello**：客户端发送支持的 TLS 版本、加密套件、随机数。
2. **Server Hello**：服务器选择 TLS 版本、加密套件，发送证书和随机数。
3. **证书验证**：客户端验证服务器证书。
4. **密钥交换**：客户端生成预主密钥，用服务器公钥加密后发送。
5. **生成会话密钥**：双方根据随机数和预主密钥生成对称会话密钥。
6. **Finished**：双方发送 Finished 消息，握手完成，开始加密通信。

## TLS 1.3 改进

- 握手次数减少，性能更好。
- 移除了不安全的加密算法。
- 默认前向保密。

## 与 HTTP 的关系

HTTPS 依赖 TLS 握手建立安全通道，之后 HTTP 数据在该通道中加密传输。
